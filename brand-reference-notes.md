# Official Black Tech Week Visual Cues

Observed on **blacktechweek.com** on 25 August 2026:

| Cue | Dashboard interpretation |
|---|---|
| Black navigation and dark visual foundation | Use near-black for the persistent portal rail and high-authority text. |
| Saturated cyan-blue content field | Use electric blue as the principal program surface and contextual field. |
| Vivid yellow ticket / CTA treatment | Use bright yellow for primary action emphasis and key status moments. |
| Acid-lime dotted menu and focus details | Use lime sparingly for path markers, state dots, and micro-wayfinding. |
| Bold, contrast-led campaign composition | Retain the partner portal’s editorial hierarchy while increasing black, blue, yellow, and lime contrast. |

The color refresh should preserve accessible copy contrast and the existing operation-first layout.
